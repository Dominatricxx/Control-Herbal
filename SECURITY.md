# Política de seguridad

Control Herbal es un prototipo / prueba de concepto. Si encuentras una vulnerabilidad, **no abras un
issue público**: usa *Security → Report a vulnerability* en GitHub o escribe al autor del repositorio.
Intentaremos responder en un plazo de 7 días.

La guía de despliegue seguro (roles, reglas de Firebase, App Check, secretos) está en
[`docs/SEGURIDAD.md`](docs/SEGURIDAD.md).
